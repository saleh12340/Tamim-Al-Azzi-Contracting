# بقالة العنزي — Al-Enezi Grocery & Ledger System

تطبيق ويب عربي RTL لإدارة المبيعات والفواتير ودفتر العملاء، مصمم للعمل محليًا وقابل للتطوير لاحقًا إلى Supabase/Firebase.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهره Vite.

## الوظائف الأساسية

- لوحة رئيسية عربية RTL.
- إنشاء فواتير مع حساب تلقائي للإجماليات.
- حفظ الفواتير والعملاء والمعاملات محليًا.
- دفتر حسابات العملاء مع عليه/له والرصيد الجاري.
- بحث العملاء والفواتير.
- مشاركة الفاتورة وكشف الحساب عبر Web Share/نسخ النص.
- طباعة فاتورة حرارية 80mm عبر CSS print.
- تصميم متجاوب للجوال وسطح المكتب.

## ملاحظات

البيانات المحلية تستخدم localStorage مع طبقة تخزين بسيطة يمكن استبدالها لاحقًا بقاعدة بيانات.
